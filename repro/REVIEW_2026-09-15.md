Reviewed branch `paper1-revision-2026` starting at `334c5ef`, including the newly
added levels 02/03 and the rename of the reduced workflow to level 04.

| Finding | Correction |
|---|---|
| Level 02 passed `--mode generation`; the CLI accepts `generate`. | Use the existing bounded `repro.smoke` runner, which also checks saved arrays and CRPS. |
| Exported `CHECKPOINT_NAME` was unused. `get_model()` derives a filename from the config/model name, including sampling steps; changing the smoke name/steps would select a different file. | Load the explicit `PUBLISHED_CHECKPOINT` through `--checkpoint`; record its path/hash/weight key. Never rename the archived checkpoint for a two-step smoke. |
| Wrapper printed PASS after any successful command, without validating output artifacts. | Propagate the runner's exit status. Only completed assertions create `smoke_result.json`. |
| Wrapper created/reused output directories before Python path checks. | Python validates input paths and chooses a fresh external output directory; repeated explicit destinations fail. |
| Bundled statistics were silently treated as the archived training statistics. | Level 02 requires an explicit `STATS_LOAD_DIR`; document that weight compatibility does not establish normalization provenance. |
| No inexpensive checkpoint/data preflight existed. | `--preflight-only` loads one date and matching weights, checks transforms, records provenance and stops before sampling. It never writes a full smoke-pass result. |
| Level 03 had empty shell/YAML files and returned success without testing anything. | Mark it unimplemented and exit 2. A training lifecycle test remains future work. |
| Level-04 launchers/readmes still referenced removed `02_reduced_run` paths. | Update local/LUMI paths and current documentation; original reduced scientific YAML is unchanged. |
| Environment instructions mixed tcsh activation and bash exports; CPU selection was implicit. | Use working tcsh examples, explain bash alternatives and request explicit `+cpu` wheel versions. |
| Synthetic README again treated runtime in seconds as a pass criterion. | Keep functional assertions; timings are observations, not acceptance thresholds. |
| A supplied file was labelled non-random simply because a path was provided. | Record source categories (`supplied_checkpoint`, etc.), without claiming artifact authenticity. |
